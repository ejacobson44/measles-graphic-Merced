A simple R script to process and visualize wastewater surveillance data tracking measles detections in Merced, California.

## Description
This project uses R to make a time series graph of measles virus concentrations over time from local wastewater monitoring. 

## Files in this Repository
* `measles_data.txt` - Time-series dataset containing detection dates and concentration values up to August 14th, 2026. 
* `Measles_Merced.R` script that reads and graphs measles data 

## Requirements
* Basic R
